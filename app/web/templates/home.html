Four questions, same shape every time

  1. How hard is this?Easy, medium, or hard, with the reason next to the label.
  2. How long until I can ship?A first test call, then the wait for production approval.
  3. What will block me?The rejection you are likely to hit, and the next move.
  4. What can an agent do?Drafts and checklists versus the clicks that need you.

How a claim earns its label

If a chip is missing a link, the sentence is not something to build a launch plan on.

  • Tested A read-only browser check opened the page and the sentence is what that page showed. The reviewed examples have none: nobody logged into a provider console to write them.
  • Sourced The sentence cites a page. On a live guide, that page is one this run actually opened.
  • Uncertain The pages did not say it. The note tells you what is missing. Treat it as a lead.
